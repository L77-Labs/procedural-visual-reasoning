# vessels

推荐 SFT 子集（`use=sft`）。开口容器 + 水平管道；水位由离散事件模拟给出。

- train：327 场景；test：100 个独立留出的 5 / 6 容器场景（train 中也含 5 / 6 容器，因此不是容器数量 OOD）
- 每场景三题：`vessels_overflow` / `vessels_never_fills` / `vessels_final_level`
- **顶沿高度、管道高度、注水口只在图上**；题干不再复述数字，必须读图
- 默认 `rationale` 由物理模拟的事件链生成；327 条由阿里云百炼正式 API `qwen3.8-max` 生成的原始教师解释保存在 `rationale_teacher`，仅作来源保留，未逐句程序核验

任务采用离散事件模型：水位达到管道阈值时触发瞬时连通，并以矩形截面计算水量和平衡状态。该定义用于生成可确定重算的标签，不用于近似真实流体动力学。5–6 容器图偶发标签贴墙或叠字，数字仍可读。
